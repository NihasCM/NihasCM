### Multi-Source Listing Pipeline

Concurrent pipeline aggregating and deduplicating listings from four travel
and mapping providers into one Postgres table.

`Python` `asyncio` `Playwright` `Supabase`

- Fault-isolated concurrent scraping via `asyncio.gather`
- Two-stage dedup: fuzzy name match, then geospatial distance
- Idempotent upserts — re-runs enrich instead of reset
- Per-source field trust: maps for coords, OTAs for price

**Status** · `Private repo`

</td>
<td valign="top" width="50%">

### Hotel Operations Platform

Property management across rooms, guests, payments, and multi-method
payment reconciliation.

`React` `TypeScript` `Tailwind` `Docker`

- Generic typed `request<T>` wrapper over six domain modules
- HTTP errors normalized at a single boundary
- CSV reconciliation matching system refs to bank refs
- UPI, GPay, PhonePe, card — matched/unmatched/pending

**Status** · `Private repo`
